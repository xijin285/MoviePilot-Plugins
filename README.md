# 🎬 MoviePilot-Plugins

MoviePilot第三方插件库，提供了一系列实用的插件来增强MoviePilot的功能。

> ⚠️ 注意：本插件库为个人维护，代码结构参考了其他开源项目。推荐优先使用[官方插件库](https://github.com/jxxghp/MoviePilot-Plugins)。

## 🔄 V2 / V3 双版本说明

本仓库同时维护两套索引，宿主会自动拉取对应的一份，同一个仓库地址在 V2 / V3 客户端添加后都能正常显示插件列表。

| 宿主版本 | 索引 | 状态 |
|---------|------|------|
| V2 | `package.v2.json` | 维护模式：不再新增功能，仅修复严重 Bug |
| V3 | `package.v3.json` | **主开发线**：新功能与优化优先发布，版本号从 3.1.0 起递增 |

> 原 V2 的「夸克网盘 (QuarkDisk)」已下架，由「夸克网盘存储 (VueQuarkDisk)」取代（V2 / V3 均可安装），已安装的用户请手动切换。

## 📖 使用说明

1. 在 MoviePilot 的插件商店页面，点击「添加第三方仓库」
2. 添加本仓库地址：`https://github.com/xijin285/MoviePilot-Plugins`
3. 添加成功后，在插件列表中找到需要的插件（V2 / V3 会自动匹配对应索引）
4. 安装并启用插件

## ⚠️ 注意事项

1. 本插件库中的插件均为个人维护，使用前请仔细阅读说明。
2. 部分插件需要特定权限或配置才能正常使用。
3. 如遇到问题，请先查看插件说明或提交 Issue；V3 插件的问题会优先处理。
4. 建议定期更新插件以获取最新功能和修复。
