# 🖥️ PVE 守护神 (ProxmoxVEBackup)

Proxmox VE 虚拟机 / 容器的自动化备份、下载、恢复与系统运维插件，带 Vue 可视化状态页与仪表盘小组件。

v3.0.0 起为 MoviePilot **V3 独立版本**，配置页 / 状态页 / 仪表盘均为 Vue 联邦组件渲染。

---

## ✨ 功能总览

| 能力 | 说明 |
|------|------|
| 🔐 SSH 直连 PVE | 通过 SSH 执行 `vzdump` / `pct` / `qm` 等命令，兼容 PVE 6/7/8，支持密码与私钥登录 |
| 💾 虚拟机备份 | 按 VMID 选择备份对象（留空备份全部），可选存储、备份模式（snapshot / suspend / stop）与压缩方式（zstd / lzo / gzip / 0） |
| ⬇️ 自动下载 | 备份完成后自动通过 SFTP 拉回 MoviePilot 本地目录，可选备份后删除 PVE 上的临时文件 |
| ☁️ WebDAV 上传 | 同时上传到 WebDAV，可单独设置保留份数，自动清理过期文件 |
| ♻️ 一键恢复 | 从本地或 WebDAV 的备份文件恢复，可指定目标存储、目标 VMID、是否覆盖已存在虚拟机 |
| 📊 状态页 | 主机负载与存储信息、虚拟机 / 容器清单，支持启动 / 关机 / 重启 / 快照等操作 |
| 🖼️ 模板镜像 | 列出 ISO / CT 模板，支持在线下载、URL 下载、上传与删除 |
| 🧹 日志清理 | 清理 journal 日志、vzdump 日志、PVE 日志、dpkg 日志与 `/tmp` 临时文件，可选清理无用模板镜像 |
| 🔔 通知 | 备份 / 恢复结果推送到 MoviePilot 消息渠道，支持失败重试 |
| 💬 远程命令 | `/pve状态`、`/pve容器`、`/pve帮助` 三个微信 / Telegram 命令 |
| 📈 仪表盘组件 | 首页仪表盘小组件展示启用状态、备份 / 恢复进行状态、备份数量与下次执行时间 |

## 📦 安装与配置

1. 在 MoviePilot 插件商店添加第三方仓库 `https://github.com/xijin285/MoviePilot-Plugins`
2. 安装「PVE 守护神」并启用
3. 打开插件配置页，按下述分区填写

### 一、基本设置

- **启用插件**：总开关
- **立即运行一次**：保存后立刻执行一次备份
- **执行周期**（Cron）：默认 `0 3 * * *`
- **通知**：备份 / 恢复结果推送到消息渠道
- **失败重试**：重试次数与重试间隔（秒）

### 二、PVE 连接

- **PVE 主机地址**：PVE 管理地址或 IP，如 `192.168.1.10`
- **SSH 端口 / 用户名**：默认 `22` / `root`
- **登录方式**：密码或 SSH 私钥文件路径

> 插件通过 SSH 调用 PVE 命令，账号需具备 `root` 或等效权限。

### 三、备份设置

- **本地备份开关**、**备份保存路径**（MoviePilot 容器内可写目录）
- **备份存储**：PVE 侧的存储名称，如 `local`
- **备份对象**：VMID，逗号分隔，留空表示全部
- **备份模式**：`snapshot`（推荐，不中断运行）/ `suspend` / `stop`
- **压缩方式**：`zstd`（推荐）/ `lzo` / `gzip` / 不压缩
- **保留份数**：本地保留最近 N 份，超出自动删除
- **下载后删除 PVE 备份**：备份文件拉回后清理 PVE 侧临时文件

### 四、WebDAV

填写地址、账号、密码与目录，并设置 WebDAV 侧保留份数；关闭时仅保留本地备份。

### 五、恢复

- **启用恢复功能**、**恢复目标存储**、**目标 VMID**（留空按原 VMID 恢复）
- **强制覆盖** / **跳过已存在虚拟机**
- 也可在状态页直接对某个备份文件点击「恢复」

### 六、系统清理

- 日志保留天数 / 份数（journal、vzdump、PVE、dpkg 分别设置）
- 清理 `/tmp` 临时文件
- 清理无用模板镜像

## ⚠️ 注意事项

- 备份大容量虚拟机时耗时较长，建议放在低峰期（默认凌晨 3 点）
- `snapshot` 模式需要存储支持快照，否则请改用 `suspend` 或 `stop`
- 恢复会覆盖同名虚拟机，操作前请确认备份文件与目标 VMID
- 插件依赖 Paramiko 进行 SSH / SFTP 通信，容器内需可访问 PVE 的 SSH 端口
