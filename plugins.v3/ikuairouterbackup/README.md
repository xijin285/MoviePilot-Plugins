# 🌐 爱快时光机 (IkuaiRouterBackup)

爱快路由（iKuai OS 3.x / 4.x）配置备份与恢复插件，附带 Vue 实时监控仪表盘。

v3.1.0 起为 MoviePilot **V3 独立版本**，前端使用 Vue 联邦组件渲染，配置页 / 状态页 / 侧边栏仪表盘均为新版界面。

---

## ✨ 功能总览

| 能力 | 说明 |
|------|------|
| 💾 多目标备份 | 本地磁盘、WebDAV、MP 网盘存储（夸克 / 115 / OpenList 等）可**同时配置多个目标**，一次备份依次写入，各自独立保留份数 |
| ♻️ 备份恢复 | 从本地 / WebDAV / 网盘任选备份文件恢复，恢复前可自动创建「恢复点」防止回退失败 |
| 📊 侧边栏仪表盘 | 路由概况（型号/固件/温度/累计流量）、WAN 线路、14 种监控与排行视图、协议流量、系统日志，卡片可自定义排序 |
| 🖥️ 状态页 | 当前状态、定时任务、最近备份、备份管理（立即备份 / 恢复备份 / 下载 / 删除）、告警记录（触发时间、峰值、恢复时间）、执行历史 |
| 🔔 负载告警 | CPU / 内存阈值超限时推送通知，可设置连续命中次数与告警间隔；告警触发与恢复均写入记录，状态页可查看与清空 |
| 🧩 IP 分组同步 | 按省份 / 城市 / 运营商抓取 IP 段，自动在爱快创建 IP 分组（供流控、分流使用） |
| 🔍 变更检测 | 配置内容哈希无变化时自动跳过备份，避免产生大量重复文件 |
| 🎛️ 面板交互 | 卡片拖拽排序 / 隐藏，刷新间隔 10·30·60 秒或手动暂停，终端与路由表可搜索、点击行复制 IP、一键导出 CSV |

## 📦 安装与配置

1. 在 MoviePilot 插件商店添加第三方仓库 `https://github.com/xijin285/MoviePilot-Plugins`
2. 安装「爱快时光机」并启用
3. 打开插件配置页，按下述五个分区填写

### 一、基本设置

- **启用插件**：总开关
- **立即运行一次**：保存后立刻执行一次备份
- **执行周期**（Cron）：默认 `0 3 * * *`（每天 3 点）
- **通知**：备份 / 恢复结果推送到 MoviePilot 消息渠道
- **爱快连接**
  - 路由地址：如 `http://192.168.6.1` 或 `192.168.6.1`
  - 用户名 / 密码：建议使用独立账号，只需「配置备份」相关权限
  - 认证方式：`自动`（优先 v4 令牌，失败回退 v3 会话）/ `v3 会话` / `v4 令牌`
  - API 令牌：认证方式选 v4 令牌时填写
- 卡片右上角**测试连接**可直接验证地址与账号是否可用

### 二、备份目标

支持多行目标，可增删：

| 类型 | 说明 |
|------|------|
| 本地磁盘 | 填写 MoviePilot 容器内可写路径，目录可点选浏览 |
| WebDAV | 需先在下方填写 WebDAV 地址 / 账号 / 目录 |
| 网盘存储 | 使用 MoviePilot 已配置的存储（夸克 / 115 / OpenList 等），目录可浏览选择 |

每个目标独立设置 **保留份数**（0 表示不自动清理）。备份文件统一命名为 `ikuai_backup_YYYYMMDD_HHMMSS.bak`。

### 三、恢复设置

- **启用恢复功能**：关闭后接口拒绝恢复请求
- **恢复前创建恢复点**：恢复前先把路由当前配置备份一份，恢复失败可回退
- **恢复后重载配置**：恢复完成后让路由器重新加载配置

恢复入口在**插件状态页 → 备份管理**卡片：点「恢复备份」打开备份文件列表，可切换 本地 / WebDAV / 网盘 三种来源，每行右侧支持：

- **恢复**：覆盖路由器配置（需启用恢复功能）
- **下载**：把备份文件取回浏览器本地保存
- **删除**：永久删除该备份文件（二次确认，不影响路由器当前配置）

### 四、监控与告警

- **启用仪表盘**：关闭后侧边栏入口与首页仪表盘卡片一并隐藏
- **负载告警**：CPU / 内存使用率、在线终端数阈值，支持连续命中次数与告警冷却时间
- 监控数据默认 30 秒缓存，避免频繁请求路由

### 五、IP 分组同步

按省份 / 城市 / 运营商筛选 IP 段，自动创建爱快 IP 分组，命名规则：

```
{前缀}_{省份}_{城市}_{运营商}      # 有前缀
{省份}_{城市}_{运营商}            # 无前缀
```

覆盖 **34 个省级行政区、306 个城市**，运营商含电信 / 联通 / 移动 / 铁通 / 教育网 / 广电及主流云厂商。创建的分组可在爱快「流控分流」「防火墙」「端口映射」中直接引用。

## 📊 侧边栏仪表盘

在 MoviePilot 左侧边栏进入「爱快路由」，卡片可通过右上角按钮上下移动，顺序自动保存。

**排版与刷新**

- **拖拽排序**：按住卡片标题左侧的 ⠿ 手柄上下拖动即可换位，松手自动保存
- **隐藏卡片**：卡片右上角眼睛按钮可隐藏该卡，顶栏「已隐藏 N」菜单可恢复
- **刷新间隔**：顶栏可选 10 / 30 / 60 秒或手动，随时点「暂停」停止自动刷新（终端、日志等静态视图不会重复请求）
- **终端类视图**（IPv4 / IPv6 / DHCP / 黑名单 / 路由表）：支持搜索框过滤、点击行复制 IP / MAC、点「CSV」导出当前结果

### 卡片

| 卡片 | 内容 |
|------|------|
| 路由概况 | 路由型号 / 架构、固件版本与构建日期、运行时长、CPU 温度、内存占用、累计上下行流量、当前连接数 |
| 线路监控 | 各 WAN 口状态、IP、上下行速率 |
| 实时监控 | 14 种视图切换（见下表） |
| 系统日志 | 系统事件 / 拨号 / DHCP / DDNS 日志，切换类型自动加载 |

### 实时监控视图（14 种）

| 视图 | 内容 |
|------|------|
| 流量/连接数分布 | 协议流量环形图、协议明细、会话数 Top |
| 终端排行 | 按累计流量或连接数排序的终端 Top10，进度条对比，可导出 CSV |
| 协议排行 | 应用协议按累计流量排序 Top15，可导出 CSV |
| 性能负载 | CPU、内存、在线终端数、连接数小时曲线 |
| 网络负载 | 上下行速率小时曲线 |
| 分流监控 | 分流策略今日 / 昨日 / 本周命中统计 |
| IPv4 终端 | 在线终端 IP、MAC、上下行速率、连接数 |
| IPv6 终端 | IPv6 在线终端列表 |
| 摄像头 | 爱快摄像头状态（需路由已绑定爱快云） |
| DHCP 终端 | DHCP 租约：主机名、IP、MAC、到期时间 |
| 黑名单 | MAC 黑名单列表 |
| DNS 设置 | DNS 模式、上游、缓存及自定义解析规则 |
| 路由表 | IPv4 / IPv6 当前路由表切换查看 |
| UPnP | UPnP 开关状态与端口映射列表 |

> 部分视图（摄像头、IPv6 终端）在路由未绑定爱快云或局域网无对应终端时为空属正常现象。

## 🔌 主要 API

所有接口前缀 `/api/v1/plugin/IkuaiRouterBackup`，鉴权 `bear`。

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/backup` | 立即备份 |
| POST | `/restore` | 恢复（`filename` + `source`） |
| GET | `/status` | 插件状态与最近备份 |
| GET | `/monitor_view?view=xxx` | 监控视图数据 |
| GET | `/protocol_flow` | 协议流量 |
| GET | `/available_backups` | 可用备份列表（本地 / WebDAV / 网盘） |
| GET | `/download_backup` | 下载备份文件（base64，供浏览器保存） |
| POST | `/delete_backup` | 删除备份文件 |
| POST | `/dashboard_layout` | 保存仪表盘卡片顺序与隐藏状态 |
| GET | `/alert_history` | 负载告警记录（触发 / 峰值 / 恢复时间） |
| POST | `/alert_history` | 清空告警记录 |
| POST | `/sync_ip_groups` | 同步 IP 分组 |
| GET | `/get_ip_blocks_info` | 预览 IP 段 |

## ❓ 常见问题

**连接失败 / 10001 错误**
- 密码使用 RSA 加密传输，请确认账号密码正确、路由版本与认证方式匹配
- 先用配置页「测试连接」定位问题

**备份成功但网盘没有文件**
- 检查该网盘在 MoviePilot「存储」中是否已配置且可读写
- 目标目录建议使用已存在的目录，或让插件自动创建

**恢复后配置未生效**
- 确认已开启「恢复后重载配置」；部分项目需重启路由器生效

**仪表盘无数据**
- 确认「监控与告警 → 启用仪表盘」已开启，且 MoviePilot 能访问路由器
- 爱快 v4 令牌模式下部分监控接口不可用，可切换为 v3 会话认证
